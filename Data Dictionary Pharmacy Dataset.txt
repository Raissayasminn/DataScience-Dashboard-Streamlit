DATA DICTIONARY – PHARMASIX DATASET
* DICT DATASET YANG MASIH ORIGIN (DOWNLOAD LANGSUNG DARI KAGGLE)
1. Date
Tipe	: Objek
Deskripsi	: Tanggal transaksi penjualan obat.
2. Year
Tipe	: Integer
Deskripsi	: Tahun transaksi
3. Month
Tipe	: Integer
Deskripsi: Nomor bulan (contoh: Januari = 1)
4. Day
Tipe	: Integer
Deskripsi	: Tanggal transaksi
5. Region
Tipe	: String
Deskripsi	: Wilayah Penjualan
6. Country
Tipe	: String
Deskripsi	: Negara Penjualan
7. Category
Tipe	: String
Deskripsi	: Kategori Obat (contoh: Vitamin, Chronic)
8. Medicine
Tipe	: String
Deskripsi	: Nama obat
9. Age_Group
Tipe	: Objek
Deskripsi	: Kategori umur konsumen
10. Units_ Sold
  Tipe	: Integer
 Deskripsi	: Jumlah unit obat yang terjual (variable target)
11. Unit_Price
Tipe	: Float
Deskripsi	: Harga per unit obat
12. Stock_Level
Tipe	: Integer
Deskripsi	: Jumlah stok tersedia
13. Expiry_days_Remaining
 Tipe	: Integer
 Deskripsi	: Sisa hari sebelum kadaluarsa
14. Covid_Flag
Tipe	: Integer
Deskripsi	: Jika 1 maka pada saat pandemi covid, jika 0 maka bukan saat pandemi covid

* DICT DATASET SETELAH FEATURE ENGINEERING 
1. Date
Tipe	: Date time
Deskripsi	: Tanggal transaksi penjualan obat.
2. Year
Tipe	: Integer
Deskripsi	: Tahun transaksi
3. Month
Tipe	: string
Deskripsi: Nama bulan (contoh: Januari, Februari).

4. Region
Tipe	: Integer (Label Encoded)
Deskripsi	: Nama wilayah penjualan. 
Catatan	: Nilai angka merupakan hasil encoding 

0. Africa	
1. East Asia	
2. Europe	
3. Middle East	
4. North America
5. Oceania	
6. South America	
7. South Asia	

5. Country
Tipe	: Integer (Label Encoded)
Deskripsi	: Negara penjualan. 
Catatan	: Nilai angka merupakan hasil encoding 

0. Argentina
1. Australia
2. Bangladesh
3. Brazil
4. Canada
5. China
6. France
7. Germany
8. India
9. Japan
10. Kenya
11. New Zealand
12. Nigeria
13. Saudi Arabia
14. South Korea
15. Sri Lanka
16. UAE (United Arab Emirates)
17. UK (United Kingdom) 
18. USA (United States of America) 

6.  category
Tipe	: Integer (Label Encoded)
Deskripsi:jenis obat
Catatan	: Nilai angka merupakan hasil encoding 

0. Antibiotic
1. Antipyretic
2. Chronic
3. Cough_Cold
4.Vitamin


7. Medicine
Tipe	: Integer (Label Encoded)
Deskripsi	: Nama obat.
Catatan	: Nilai angka merupakan hasil encoding 

0. Amlodipine
1. Amoxicillin
2. Azithromycin
3. Cetirizine
4. Cough Syrup
5. Ibuprofen
6. Metformin
7. Multivitamin
8. Paracetamol
9. Vitamin C

8. Age_group
Tipe	: Integer (Label Encoded)
Deskripsi	: Kelompok usia konsumen 
Catatan	: Nilai angka merupakan hasil encoding 
 0 = 0 – 12
 1 = 13 – 25
 2 = 26-45
 3 = 45-65
 4 = 65+
		  
9. Units_ Sold
  Tipe	: Integer
 Deskripsi	: Jumlah unit obat yang terjual (variable target)
10. Unit_Price
Tipe	: Float
Deskripsi	: Harga per unit obat
11. Stock_Level
Tipe	: Integer
Deskripsi	: Jumlah stok tersedia
12. Expiry_days_Remaining
 Tipe	: Integer
 Deskripsi	: Sisa hari sebelum kadaluarsa
13. Month_num
 Tipe	: Integer
 Deskripsi	: Representasi numerik bulan (1 – 12)
 
 
14. Quarter
 Tipe	: Integer
 Deskripsi	: Kuartal dalam satu tahun (1 – 4)
15. Lag_1
 Tipe	: Float
 Deskripsi	: Penjualan pada periode sebelumnya
16. Lag_3
 Tipe	: Float
 Deskripsi	: Penjualan tiga periode sebelumnya
17. Rolling_mean_3
 Tipe	: Float
 Deskripsi	: Rata – rata penjualan tiga periode sebelumnya
18. Growth_rate
 Tipe	: Float
 Deskripsi	: Perubahan persentase penjualan dibanding periode sebelumnya
20. Price_change
 Tipe	: Float
 Deskripsi	: Perubahan persentase penjualan dibanding periode sebelumnya
21. Coverage
 Tipe	: Float
 Deskripsi	: Rasio stok terhadap permintaan
 
22. Near_expiry
 Tipe	: Integer
 Deskripsi	: Indikator obat mendekati kadaluarsa. 
 Contoh	: 0 = Tidak
 		  1 = Ya
